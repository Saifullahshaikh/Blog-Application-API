# Blog Application API

Backend REST API project for a blog application, focused on clean Python API structure, authentication, validation, and database-backed operations.

## Overview

This repository demonstrates a backend service for common blog workflows such as user management, authentication, posts, and related API operations.

## Key Areas

- Python backend development
- REST API design
- Request/response validation
- Authentication and authorization concepts
- Database integration
- Modular project structure

## Project Structure

The repository is organized into separate application layers such as models, schemas, and services to keep responsibilities clear and maintainable.

## Local Setup

1. Clone the repository.
2. Create a virtual environment.
3. Install the project dependencies.
4. Configure required environment variables locally.
5. Run the application using the project's configured entry point.

> Keep credentials and secrets in a local `.env` file. Do not commit `.env` to Git.

## Development Notes

Generated files, Python caches, local virtual environments, IDE settings, local databases, and secrets are excluded through `.gitignore`.

## Purpose

This project is part of my Python backend portfolio and demonstrates API-oriented application development and separation of backend concerns.
